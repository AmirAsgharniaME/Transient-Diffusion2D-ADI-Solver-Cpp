# Transient-Diffusion2D-ADI-Solver-Cpp

A modular C++ finite difference solver for the 2D transient diffusion equation using the ADI method.

## Project Information
- **Author:** Amir Asgharnia
- **Environment:** Linux Mint (GCC, GNU Make, GDB, VS Code)
- **Repository:** [Transient-Diffusion2D-ADI-Solver-Cpp](https://github.com/AmirAsgharniaME/Transient-Diffusion2D-ADI-Solver-Cpp)
